# WinGeul (윈글) — 블로그 상위노출 원고 관리

네이버 상위노출을 위한 블로그 작성 데스크톱 앱. 대행사·마케터가 업체별로 쓴다.
`상위노출 분석 → 고객 심리 → 컨셉 → 제목 → 원고 → 이미지 → 검수 → 네이버용 복사 → 순위 체크`

- 사용자 본인의 Claude API 키(BYOK). 키는 OS 키체인으로 암호화해 이 PC에만 저장
- 네이버 수집은 이 PC의 브라우저(숨김 창)로 실행. 서버 없음
- 자동 로그인·자동 발행은 하지 않음 → "네이버용 서식 복사" 후 스마트에디터에 붙여넣기

## 다운로드

- 소개·다운로드 페이지: https://hubhub5.github.io/wingeul/
- 설치 파일: https://github.com/hubhub5/wingeul/releases/latest (Mac Apple Silicon·Intel `.dmg`, Windows `.exe`)
- 새 버전 배포: `npm version patch && git push --follow-tags` → GitHub Actions가 Mac·Windows를 빌드해 Releases에 올립니다.

## 실행

```bash
npm install
npm run dev        # 개발 실행
npm test           # 검수·서식 엔진 단위 테스트
npm run typecheck
npm run dist:mac   # 배포 파일 (release/)
```

개발자 점검 모드:

```bash
WG_MOCK=1 WG_DATA=./e2edata npx electron . --e2e=./e2e   # API 없이 화면을 실제로 클릭하며 전 기능 점검 (23항목)
npx electron . --post=블로그URL                          # 예시 글 구조(컴포넌트 순서) 확인
npx electron . --render-brand=./build                     # 스플래시·아이콘 PNG 렌더
npm run build
npx electron . --spike=대구임플란트          # 네이버 수집 결과를 JSON으로 출력 (셀렉터 점검)
WG_DUMP=./dump npx electron . --spike=키워드  # 원본 HTML도 저장
```

## 구조

| 위치 | 내용 |
|---|---|
| `src/shared/analysis` | 글자수·문장 분리, 경쟁글 압축, 유사문서, AI 티, 제목 점수, 팩트 잠금, 통합 검수 (토큰 0) |

| `src/main/services/naver` | 숨김 Chromium 수집기, DOM 추출기, 자동완성, 순위 확인, 홈페이지 크롤 |

## 이번에 추가된 것

- 예시 글 형식 학습: 원장 인사 → 대표 이미지 → 환자 질문 → 결론 먼저 → 전화문의 → (번호 소제목 → 이미지 → 본문)×N → 비교표·체크리스트 → 링크·지도 골격, 형광펜·환자 질문색·글자 크기 자동 추출
- 새 블록: 번호 소제목 박스, 비교표, 전화문의 박스, 링크, 짧은 줄바꿈 문단
- 이미지 생성: 썸네일(원장 사진 참고)·인포그래픽은 Gemini(사용자 키), 키가 없거나 '카드로'는 무료 로컬 렌더. 이미지 안 문구는 원고 작성 때 함께 만들어져 이미지 단계 Claude 비용 0
- 고객 심리 분석 7개 탭: 고민 지도(심리 기제·강도·원고 방향), 페르소나(숨은 니즈·검색 계기), 감정 온도·심리 기제 분포·결정 장벽/촉진, 설득 장치 히트맵(9종), 검색 의도 단계, 고객 언어, 반론 처리표
- 원고 검수의 설득 구조 점검: 흐름 6단계, 첫 3줄 후킹, 고민 반영률, 독자 지칭, 구체성, 이탈 위험 구간
- 디자인: Material 3 감각, 딥 파인·아이보리·샴페인 골드, 나눔스퀘어 네오(앱에 포함), 자간 -0.07em, 스플래시·앱 아이콘

## 비용 설계

- 분석은 Haiku 5.5, 앵글·제목·본문은 Sonnet 5.5 (설정에서 변경)
- 작성 단계 3~4회 호출이 같은 접두부(시스템·브랜드 두뇌·전장 정보)를 공유 → 캐시 적중
- 경쟁글은 로컬에서 압축(글당 1800자 상한), 캡처 이미지는 LLM에 보내지 않음
- 수집 결과는 키워드별 24시간 캐시, 부분 수정은 선택 블록만 재생성
- 예상: 글 1편 약 $0.06~0.08 (실측 전 추정치)
